Rc car with ESP32

Bluetooth Remote Control via Xbox Controller

This project consists of a four wheeled vehicle remote controlled via Bluetooth BLE. Communication between the Xbox controller and the vehicle is handled by an ESP32, Wich reads the left joystick values and drives two DC motors through anH bridge(L298N).

LibraryUsed

XboxSeriesXControllerESP32_asukiaaa

  • Author:asukiaaa.
  • Ptrotocol: Bluetooth Low Energy(BLE).
  • Installation: Arduino Library Manager or Github.
